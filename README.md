# Fraud Shield AI

## An Intelligent AI-Powered Online Transaction Fraud Detection and MLOps Platform

Fraud Shield AI is an end-to-end machine learning and MLOps project for detecting fraudulent online transactions.

## Technologies

- Python
- Pandas
- Scikit-learn
- DVC
- MLflow
- FastAPI
- Streamlit
- Docker
- GitHub Actions

## Project Objectives

- Detect fraudulent transactions
- Version datasets using DVC
- Track ML experiments using MLflow
- Compare multiple ML models
- Select the best-performing model
- Deploy the prediction service using Docker
- Implement CI
- Implement automatic model retraining
